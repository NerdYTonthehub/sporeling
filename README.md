# Sporeling

make a  2d sidescroller pixelgame where you are a little little mushroom with eyes arms and legs walking around in a GIANT forest. You can find other mushroom people in mushroom villages around the world. Add a health and hunger bar and add little trees that grow apples that you can eat.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://sporeling.lovable.app
